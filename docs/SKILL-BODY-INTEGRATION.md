## 资源、时钟与层级

- 正式登记：`dist/assets/skill-body/manifest.json`；运行绑定：`dist/skill-body-assets.mjs`。
- 正式素材：`dist/assets/skill-body/atlas_*_soft_v*_final.png`，12张透明PNG，1024×512；每张4列×2行、8个256×256关键帧，中心锚点(0.5,0.5)。与当前审核图集逐字节一致，版本沿用源图集。
- 彩色万能块：`tile_wild_star_soft_v1_final.png`，128×128、中心锚点，仅用于彩虹核心。方块外观在双方共享绘制器中随真实位置移动，保留特殊方块规则。
- 读取事件：`dist/skill-body-vfx.mjs`；绘制：`dist/effect_skill_body_soft_v1_final.mjs`；正式游戏不导入审核页、规则模拟或审核时钟。
- 主反馈：火焰/裂地720ms，冻结/黑洞/炸弹/超载760ms，陨石/风暴/迷雾/贤者/彩虹/幸运800ms。关键帧在透明临时画布插值，最终普通source-over合成，不对棋盘叠加爆亮。
- 通用施法沿用原200ms释放、180ms开始飞行、380ms飞行、400ms命中收尾。技能主体通常在真实飞行结束后80ms展开，常规出牌即640ms。目标延迟确定的彩虹核心随实际恢复的通用飞行同步，不伪造落点。
- **规则时刻优先**：即时技能的真实清除、轮转或变色可与飞行并行，不为了视觉叙事延后结算。黑洞轨迹只在实际移动期间绘制；排队技能以实际生效事件触发结算反馈。延迟攻击按原有安全提交时刻清除；迷雾6秒结束即释放规则限制，1.2秒尾雾仅为消散。
- 持续状态按真实截止时间消失。重复冻结/迷雾替换旧视觉期限，避免旧特效提前解冻。结束、退出、重开清理通用动画、本体、图标和倒计时。

本轮只有两处获用户批准的规则变更：裂地由固定最底行改为指定横排；迷雾由随机散布12格改为落点附近按距离取12个有效普通格。AI沿用雾内禁止新交换，未新增玩家输入封锁。能量、计分、抽牌、幸运概率、自动操作间隔及其余技能时序沿用正式规则。

## 重建与回退

`node scripts/sync-skill-body-assets.mjs` 按已批准manifest复制终稿并生成绑定。批准后的审核素材重建脚本会保留登记选择，避免恢复旧候选。裂地卡面仅同步标题/规则文字，沿用原框和原画；`scripts/update-quake-card-label.mjs` 登记新版，卡面重建优先保留该终稿。

将 `dist/skill-body-assets.mjs` 的 `SKILL_BODY_ENABLED` 改为false可关闭本体、底光、增益轨道和新万能块贴图，保留通用施法与当前规则。此开关只用于表现回退；完整代码回退需从Git历史恢复对应文件，不能用关闭特效代替回退玩法。原图、审核入口和被否定的流光源稿保留追溯，正式运行不加载被否定素材。

静态试玩：服务 `dist/`；单文件版运行 `npm run build:offline`，双击根目录 `方块乱斗-最新版.html`。当前约28.39MB、107份内嵌媒体；该可重建产物按既有规则仅保留本地。未更新历史Sites部署。
