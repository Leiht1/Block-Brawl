# 素材命名规范

新资源使用小写英文、下划线分段、明确版本与状态。旧文件可保留兼容名称，通过 manifest 映射，不能以旧路径为由丢失版本记录。

## 格式

`{类型}_{用途/技能ID}_{方向或类型}_v{主版本}_{状态}[_{帧号}].{扩展名}`

状态：`preview` 为预览/集成审稿稿；`final` 为用户明确确认的终稿。未获终稿确认不能将 preview 改名 final。版本从 v1 递增；结构/构图/方向明显修改递增主版本，旧源稿保留。

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 卡牌立绘/技能图案 | card_skill_firewave_soft_v4_preview.png | 独立画窗源图 |
| 黑洞技能图案 | card_skill_blackhole_soft_v4_preview.png | 各技能使用独立ID |
| 卡框 | card_frame_attack_v3_final.png | 进攻/control/buff，须有用户确认来源 |
| 手牌卡面 | card_face_fire_soft_v4_preview.webp | 完整卡面；与画窗来源分开登记 |
| 释放效果 | effect_cast_orb_soft_v1_preview_01.png | 两位帧号，从01连续递增 |
| 释放效果下一帧 | effect_cast_orb_soft_v1_preview_02.png | 与前帧同尺寸、锚点 |
| 命中效果 | effect_cast_impact_soft_v1_preview_01.png | 通用落点，不混入技能本体 |
| 图集 | atlas_cast_attack_soft_v1_preview.webp | manifest 登记行列、单元尺寸、帧数 |
| 序列帧清单 | sequence_cast_soft_v1_preview.json | 帧时长、循环与透明锚点 |
| 程序绘制效果 | effect_cast_soft_v1_preview.mjs | 可编辑代码源，登记版本与参数 |

## 登记要求

manifest 至少记录：类型、技能ID/类别、版本号、状态、源文件、正式运行路径、来源/生成方式、当前是否终稿、当前是否预览稿。图集额外记录 frameSize、columns、frameCount、frameMs、anchor；程序特效记录生命周期、尺寸与透明度上限。小样审核记录另存，不能以“已接入”代替“已确认”。

`fire`（运行时ID）与 `firewave`（语义素材名）等别名在 manifest 明确映射；任何重建脚本必须读取当前 manifest，不能悄悄恢复旧版。
