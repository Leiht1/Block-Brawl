# 方块乱斗 · 卡牌竞技

本轮在既有人机对战外增加独立卡牌系统。原 `engine.mjs` 与 `bot.mjs` 未修改；地图、交换、三消、特殊块和连锁规则继续使用现有引擎。

## 本局流程

人机难度 → 随机地图揭晓 → 双方选六张卡 → 双方准备 → 3秒倒计时 → 开战。

选择阶段限时60秒，展示当前地图场景、棋盘形状和环境规则。每类最多2张，六张完整卡组为进攻、控制、强化各2张；玩家替换、AI随机选择和超时补齐均遵守限制。AI界面仅显示数量和卡背。玩家可点击卡槽再点卡池替换，或点×移除；满六张显示准备按钮，准备后锁定卡组。超时保留已有选择，随机补齐不同卡并自动准备。双方准备后显示同步3、2、1倒计时，期间不增长能量、不操作棋盘。开战沿用揭晓的地图，三档难度统一15000目标分，无比赛时限。

**初始手牌0张，初始能量0。** 六张卡组仅构成本局抽牌池；每个六张抽牌循环重新洗牌，循环内无重复，跨循环可以重复。

## 能量、手牌与预览

所有数值在 `dist/cards.mjs` 的 `CARD_CONFIG` 中配置。当前默认值：

| 参数 | 数值 |
| --- | --- |
| 手牌上限／卡组数量 | 6／6 |
| 每类卡组上限／选卡时间 | 2／60秒 |
| 初始手牌／能量 | 0／0 |
| 最大能量 | 100 |
| 自然增长 | 每秒8 |
| 有分数的消除奖励 | 每个消除方块0.8 |
| 落后补偿 | 每落后1000分，每秒多1.5能量；最高多6 |
| 最小释放拖动距离 | 48像素 |
| AI出牌检查间隔 | 4.2秒 |

自然增长在经过的实际比赛时间内持续计算；消除奖励越过100后立即抽一张并清零，超出的奖励不储存。满手时新卡成为暂存预览，下一张满能量新卡覆盖它。成功出牌后暂存卡自动入手；未满手时左侧展示下一张将抽到的卡。

手牌扇形重叠，悬停／点击单张放大并置于前景。按住拖到对应棋盘的有效格释放；拖动不足、落错棋盘、空洞和障碍等无效目标都返回且不消耗。能量槽到手牌／暂存区有入场动画，出牌有离场动画；抽牌不销毁正在拖动的卡牌节点。

对战使用透明紧凑手牌区，移除右侧说明。正常手牌96×132，悬停放大1.5倍；Logo固定背景左上角，操作按钮置于棋盘右侧。只改变对战排版，教学与沙盒布局沿用原设置。

## 十二张效果

| 卡牌 | 目标 | 当前效果 |
| --- | --- | --- |
| 火焰冲击 | 敌方 | 标记随机3个普通格，2.2秒后烧毁 |
| 地裂冲击 | 敌方 | 破坏棋盘最底部一行的有效方块 |
| 陨石坠落 | 敌方 | 随机区域预警，1.6秒后3×3爆炸 |
| 炸弹投放 | 敌方 | 释放格为中心，1.8秒后3×3爆炸 |
| 时间冻结 | 敌方 | 3秒内禁止新交换，已提交操作结算；手牌仍可释放 |
| 黑洞吸引 | 敌方 | 循环牵引6个普通方块，改变它们的位置 |
| 混乱风暴 | 敌方 | 6个普通方块随机改成其他颜色 |
| 迷雾领域 | 敌方 | 遮挡12格6秒；AI不会在被遮挡格上执行新交换 |
| 超载模式 | 己方 | 10秒内正常消除得分×2 |
| 贤者时间 | 己方 | 5秒自动评估可见棋盘最佳交换，暂停手动棋盘交换 |
| 彩虹核心 | 己方 | 普通格变万能方块；与相邻方块交换时消除该颜色全部方块 |
| 幸运星 | 己方 | 10秒内补充块有22%概率成为清行／清列／爆破块 |

攻击本身不给被攻击者分数／能量；之后实际形成的普通连锁仍按原规则结算。卡牌改动等待已有事务和地图列预留释放，在安全状态提交；已到期的待执行卡效果阻止目标提交新的交换，避免连续操作无限推迟效果。延迟爆炸加入竞技时钟，掉帧时按真实截止时间结算。既有空洞、障碍、临时地图封存和冻结身份受到保护。

达到15000立即锁定胜者，停止AI和卡牌来源并取消尚未执行的卡效果；按原比赛规则等待已经提交的棋盘事务结算，再显示最终分数。重开、取消准备、返回和结束会清理卡牌、预警、拖动与动画。

## 验证与试玩

在静态服务中打开 `dist/index.html` 试玩；需要单文件离线版时，先运行 `npm ci`、`npm run build:offline`，再双击根目录 `方块乱斗-最新版.html`。该构建产物不纳入Git。本轮没有发布线上版本。

规则回归：`node --test tests/*.test.mjs`。浏览器验收：`node scripts/validate-cards.mjs`（本机Edge与现有Playwright依赖）。单文件更新：`node scripts/build-offline-html.mjs`。

最新浏览器报告和关键帧保存于 `validation/2026-10-11/cards-refinement/`，首版记录保留在 `cards/`。验证覆盖零初始手牌、双方六张卡组、每类限额、隐藏AI选择、60秒准备／超时、3秒开场、能量与补偿、十二效果、手牌交互、抽牌期间持续拖动、四种桌面布局、地图安全边界、完整真实AI比赛、15000结算及离线入口。卡牌数值仍是首版试玩参数，美术采用符号和颜色区分。
