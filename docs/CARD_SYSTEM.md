# 当前卡牌系统

截至2026-10-12，运行参数以 dist/cards.mjs 的 CARD_CONFIG 为准；首版记录归档于 history/CARD_SYSTEM-2026-10-11.md，旧参数不代表当前版本。

随机地图揭晓后，60秒内自由选六张不同卡，没有类型配额。双方准备后倒计时3秒开战；初始手牌与能量均为0，先到15000分获胜。自然能量每秒1，有分数的消除每块增加0.8，100能量抽牌并保留溢出能量；无落后补偿。手牌上限6，满手新卡依次暂存，不覆盖旧卡。抽牌按权重随机：强化权重0.45，每张强化卡一局最多生成/使用一次；其他卡权重1。拖动至少48像素并落到正确棋盘的有效格才释放。

迷雾遮挡在落点，AI沿用“被遮挡格不能提交新交换”的逻辑；玩家依照实际视线操作，未新增玩家输入封锁。攻击本身不奖励目标分数/能量，后续普通连锁仍使用既有计分。卡牌等待事务和地图预留释放后提交，不为特效更改截止时间。即时生效的技能可与通用飞行并行：真实移动/变色/清除按规则时刻反馈，技能主体在通用命中后衔接，不伪造二次结算。
