## 风格与状态约定

整体：浅色砂岩、象牙纸面、蜂蜜木、少量青金魔法沟槽。环境安静，卡牌主图鲜明；不是写实厚重暗黑风。卡牌中央采用真正绘画主图，说明控制在两行。类别同时依靠颜色和徽记辨认：进攻珊瑚红/火纹；控制冰蓝/环形符文；强化蜜金翡翠/星冠。整体框体比例保持统一。

正常：克制描边，主图最醒目。悬停：亮边、置顶浮起；已选：青金双边和勾选章；禁用/已使用：灰石材和锁章。拖拽：卡牌保持主体可读，轮廓发光，合法目标显示小范围提示；不可释放时使用锁态、取消目标提示。拖拽与合法/非法姿态见战斗方案，尚无单独动画序列。

## 可用于后续接入的程度

- **接入候选：22项独立基础素材 + 6张组合卡。** 包括6张主图、3类正常卡框、12个UI组件、1张独立环境背景；均可离线加载，底板/卡槽/卡框真实alpha。卡名、说明与目标分层可编辑；组合成品可作静态卡面。本轮未审定，称接入候选而非已完成正式绑定。
- **状态预研：9个悬停/已选/禁用卡框。** 可审查/下载，图集光晕在部分单元边缘过近；下一轮需给各状态统一透明留边、修去邻格微小溢光，再作正式状态资源。锁章也可用于已使用示意，实际可用性由原规则决定。
- **风格/布局预研：3张完整界面图和6个特效关键姿态。** 界面图不作为整屏背景强行接入。生成方案中的小字、局部示例名称和禁用示意不作为规则文案。B已纠正下方12牌池重复卡；准确文案以组合卡和card-layout.json为准。
- **特效图仍需生产清理。** 带色雾与静态关键姿态不等于可用序列，未完成逐帧动画、目标坐标、alpha边缘、亮度/粒子预算、释放取消和音效同步。不能直接将整图贴在棋盘上作为技能成品。

卡框有效源分辨率约320×440。3x组合PNG的文字由浏览器高密度渲染，卡框是放大显示，不是原生3x新绘。用于当前约116px手牌足够；若正式悬停卡需要超过320px宽，下一轮应以单独高分辨率框图重绘。主图保留834px宽源切片，可继续扩大。PNG源稿没有PSD层；本包用独立文件+文字层代替。

## 布局接入契约（待评审后执行）

选卡：保留左右玩家/AI分区及下方卡池；玩家六槽，AI六张卡背保密，60秒模块、准备按钮、地图信息单独叠放。方案中的类别标签仅作筛选视觉方向，本轮没有添加筛选玩法。面板不整体拉伸到任意长宽，不批准九切片参数；大尺寸分区采用原画底板等比裁放，后续按实际视口重绘背景或单独边片。饰叶不侵入文字、按钮命中区域。

战斗：两方棋盘的有效格、平台轮廓、480×480坐标以及中央比分结构继续沿用原项目。生成战斗方案的环境材质有绘画微调，仅作为协调效果参考；实际接入不要替换棋盘地图。手牌底座约占参考画面底部24%（1366×768需重新测量）。六牌组成浅弧；少牌舒展、多牌重叠，悬停抬高并旋转归零，不能遮挡比分与可操作格。手机审稿页正常并不代表手机战斗布局已验收。

预告与能量共享青金沟槽。能量填充使用画好的纹理按百分比裁切，不拉伸改变纹理颗粒；数字独立文字。能量满100生成卡牌，不设计单卡费用数字。手牌0/6与满手6/6均预留文本位置；未制作六个新增规则或12张技能接入。强化卡单局一次沿用现有定义，不由美术状态驱动规则。

## 下一轮建议顺序

1. 先确认选卡A/B、装饰密度、三类卡框和战斗手牌尺寸；精修透明边缘、留白、分辨率与状态章。
2. 接入已确认的卡框/主图/卡槽/托台/能量/预告，复用现有交互与规则，先测桌面与窄屏遮挡和命中。
3. 完成共用释放链路：拖出激活→合法松手闪光→从原手牌位置生成光团→曲线飞向棋盘→命中爆点→技能本体。非法松手仍返回手牌；动画不得负责消费卡或结算。
4. 释放节奏参考：激活80–120ms；闪光60–100ms；飞行250–450ms随距离；命中80–120ms；展开120–220ms。只是美术节奏建议，须与原规则时钟对齐，不能擅自改变2.2秒火焰、3秒冻结、1.6秒陨石等效果时间。
5. 先制火焰（定向三格）、冻结（透明冰层/碎冰）、黑洞（牵引六普通块）、陨石（纵向最多五格+两侧冲击，障碍截断）；再制作贤者/彩虹及剩余六牌。每项先导出干净alpha/分层/关键帧，再对照真实目标格接入。
