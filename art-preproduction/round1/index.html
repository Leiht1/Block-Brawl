卡牌释放的绘画方向

拖出 → 松手闪光 → 手牌位置生成光团 → 飞向目标 → 爆点 → 技能本体。本轮交付静态关键姿态，不是完整动画序列。

  1. 激活：窄边光框，不遮住主图。
  2. 松手：短闪光；合法释放后生成光团。
  3. 飞行：青金共用核心，用类别色轻染外层；拖尾沿曲线舒展。
  4. 命中：小爆点先于技能展开，保持目标格可读。
  5. 技能本体：先完成火焰、冻结、黑洞、陨石，再制作强化与余下卡牌。
