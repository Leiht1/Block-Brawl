# 战斗主体居中

将桌面对战的布局改为左棋盘、记分牌、右棋盘三列，整体以屏幕中线居中。右侧操作按钮移出布局，独立固定到屏幕右边，保留20像素边距。抵消原有预留滚动条空间，使记分牌准确位于屏幕中央；左右棋盘距记分牌对称。窄横屏保留对称空间避免按钮遮挡操作区。

仅修改 dist/style.css 的桌面对战布局规则，并同步最新版离线游戏与五地图审查页。已确认的15份美术、地图格子及缺口、卡牌、按钮外观、玩法保持。

验证五张地图和六种横屏尺寸：记分牌与双棋盘中心对齐屏幕中线，左右间距一致，按钮固定靠右且不遮挡操作格。1672×941下棋盘尺寸保持480×480。最新版离线游戏实测通过，无页面错误。
