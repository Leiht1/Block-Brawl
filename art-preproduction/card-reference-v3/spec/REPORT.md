# 卡片外观调整

以用户的三张示意图为准。统一顶部居中图标、原画下方类型牌、居中标题/说明/目标；保留红金/蓝金/青金分类。使用内置 imagegen 图像编辑，直接以示意图为输入，文字为原画内美术字，不使用之前的普通系统字体覆盖。完整提示词保存在 prompts.json。

时间冻结、彩虹核心原图原样保留，其余十张按对应示意图调整。完整卡片位于 cards/{fire,meteor,quake,bomb,freeze,blackhole,storm,fog,rainbow,sage,overload,luck}.png。

本轮为卡片外观审稿稿件，未接入正式游戏，未修改地图、棋盘、逻辑和动画。生成图的文字是烘焙的；后续接入前仍需将确认的字形与卡框提取为可复用素材，并检查透明外缘，不把本页直接宣称为最终生产素材。

用户“绝对不默认生成太写实的图片”的偏好已记录到全局 AGENTS.md 与 docs/CARD-ART-REFERENCE.md。
