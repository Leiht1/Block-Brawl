## 必须区分的两种时序

现有通用施法保持原样：准备阶段240ms，提交后180ms起飞，380ms飞行，命中后400ms原通用余辉。本体建议在命中后80ms展开，不等待全部400ms余辉。也就是审核页从0ms开始，240ms提交，800ms命中，880ms本体展开。

**完整衔接示意**：用于审“手牌→飞行→命中→本体→收尾”。只有黑洞将实际规则事件的视觉重放延后640ms，从880ms开始，起终点、方块身份与420ms移动曲线保持真实数据；此重放不代表正式玩法发生在该时点。

**真实规则时序**：直接显示现有引擎数据。黑洞在提交时240ms立即轮转，420ms反馈至660ms，通用光团800ms才命中，因此黑洞核心与通用飞行会重叠。冻结与幸运在240ms提交时已经生效；主本体880ms展开，页内状态文字从真实生效时点开始。火焰按提交后2.2秒结算。

现有即时黑洞规则与“必须命中后才开始牵引”的叙事不能同时完全成立。本轮优先保留真实规则、提供高质量审核，不更改结算或通用施法来掩盖冲突。正式接入前需确定是接受即时控制与施法重叠，还是另行授权调整通用表现的时点；本轮未作这种调整。

## 素材与结构

- `source/effect_{技能语义名}_soft_v1_preview.png`：内置 image_gen 原始透明源稿，1536×1024，4列×2行。无覆盖旧稿。
- `source/prompt_{运行时ID}_soft_v1_preview.txt`：每张实际生成提示词。生成方式为内置 image_gen，没有使用API/CLI替代。
- `source/effect_{技能语义名}_soft_v2_preview.png`：原始源稿的确定性调色副本，不重画。
- `source/effect_{技能语义名}_soft_v3_preview.png`：冻结为内置image_gen编辑生成的冰壳源稿，其余3张为确定性调色副本；冻结实际提示词另存v3文件。
- `assets/atlas_{技能语义名}_soft_v3_preview.png`：当前透明图集，1024×512，4列×2行，每格256×256，8张关键帧。v1、v2图集保留。
- `assets/effect_{技能语义名}_soft_v3_preview_01.png` 至 `_08.png`：当前拆帧；除冻结新材质外，其余3张与v1、v2像素坐标和空白alpha区域完全一致。
- `manifest-v2.json`、`color-revision-v2.json`：上一版参数和调色记录。v3参数在当前manifest内，可通过 `scripts/enhance-skill-body-v3.mjs` 重现；火焰、黑洞、幸运源alpha分别为原稿的2.3 / 2.4 / 2.3倍，主反馈绘制alpha均为1.0。
- `manifest.json`：ID别名、源稿、图集、拆帧、版本、preview状态、时长、中心锚点、alpha预算及实际期限。`runtimePath:null` 明确尚未进入正式运行资源。
- `effect_skill_body_soft_v1_preview.mjs`：仅审核页导入的本体绘制模块；依实际格宽缩放，范围裁切到棋盘/真实技能目标格。
- `rule-trace.mjs`：隔离审核场景，使用原规则收集事件；不写入正式游戏。
