## 实际试玩

打开 [本机试玩入口](http://localhost:5173/)，点击「新手教学」，即可进入下列四个关卡按钮；首次体验顺序解锁，已通关关卡直接重玩。也可直接双击项目根目录的 `方块乱斗-最新版.html`。

| 关卡 | 玩家亲自完成的操作 |
| --- | --- |
| 方块入门 | 亮框三消 → 四消生成光束 → 触发自己生成的光束并得分 |
| 地图会捣乱 | 观察真实悬崖预警／落石 → 障碍后的消除 → 五张现有地图图文 |
| 魔法卡牌 | 消除充能 → 补满抽牌并飞入手牌 → 准星释放进攻、控制、己方强化 |
| 卡牌策略 | 正式规则自由试选6张 → 预设手牌先保留 → 冻结对方交换 → 连续进攻 |

策略练习明确提供固定的冻结＋火焰手牌；正式对局仍从玩家选择的6张卡抽牌。教学目标约6–8分钟，不设置强制等待；实际新手阅读／操作时长尚需人工试玩。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 教学与原底层 | 23项通过；预设三次真实操作、实际地图事件、三类技能、及时配合／超时重试 |
| 必要关联规则 | 65项通过；正式卡牌、能量、技能限制与地图机制 |
| 离线包 | 2项通过；程序语法与全部来源哈希一致，117份内嵌媒体 |
| Edge实际操作 | 9组通过；顺序解锁、重玩、退出／重开／刷新、旧六关存档、能量／抽牌／准星／Buff及全通关 |
| 选关与离线专项 | 各1组通过；全通关提示与自由重玩、离线真实交换且零外部请求 |
| 桌面布局 | 四关在1440×960、1366×768、1024×768、1024×600窗口内提示、棋盘、手牌及操作区可见；17份测量 |
| 准备按钮位移 | 上述4种桌面及390×844；选满／移除第6张卡，面板、标题、卡槽、卡池及返回按钮边界差值均为0 |

共90项必要检查、11组浏览器验收通过，无浏览器脚本错误。浏览器验收通过真实点击、交换与拖放，使用受控时钟推进实际规则；未使用自动通关或修改玩法状态替代玩家操作。旧版全部通关用户保留资格，部分旧进度重新按四关教学；新进度首次通关立即保存，重玩不重复写入／奖励。

正式对局继续按现有0初始能量／手牌、每秒2点自然能量、15000分及当前五图规则运行。现有竞技资格门槛保持；联网匹配尚未实现，本地人机对战可用。未修改已确认背景、棋盘、卡牌原画或技能特效，未做无关模块全量回归。
