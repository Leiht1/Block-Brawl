状态：7组 × A/B/C = 21条，全部待用户试听确认，未选定正式版本。仅完成首轮；其余8张技能只保留清单。

## 打开与试听

双击同目录 `index.html`，用 Edge / Chrome 打开即可离线试听。声音和原有正式参照音频署名均嵌入页面，不需要启动游戏、联网或安装依赖。首次点击播放才启用声音。

1. 各组可以单独播放或连续对比 A → B → C；点击“停止全部”或按 Esc 立即取消后续播放，并用12ms淡出结束当前声音。
2. “用于本次组合”只改变当前页面内存。初始都是A，仅为可直接播放的初始值，并非推荐或确认。
3. “播放完整施法”提供真实动作时序，以及释放→飞行→命中→本体的顺序对照。冻结、幸运星的真实生效在0ms，因此真实模式不会把它们人为推迟到命中后。
4. 可混入当前正式对战/大厅BGM、普通消除、行列/爆破/三种组合消除；倍率直接读取当前音频清单。整页音量统一调节，A/B/C没有单独加响按钮。
5. “双方连续施法”以420ms间隔交替6次，检查声音重叠。默认音效上限3条；可切换8条对照。这里只模拟声音，不模拟双方棋盘、冻结或结算规则。
6. 每条下方展开来源、作者、授权、实际时长和精确处理。可下载独立WAV。页底可填写备注并下载试听意见；刷新恢复初始组合。

## 当前真实技能时序依据

已阅读 `AGENTS.md`、`docs/art/`总规范/卡牌技能/特效/命名与参考说明、`docs/audio-design.md`，并以当前 `dist/audio-manager.mjs`、`audio-manifest.mjs`、`audio-events.mjs`、`cards.mjs`、`card-cast-vfx.mjs`、`card-effects.mjs`、`skill-body-vfx.mjs`的真实代码为准。历史音频文档中的倍率或旧技能描述不覆盖当前实现。

| 技能 | 真实动作与本轮试听依据 |
| --- | --- |
| 火焰冲击 | 安定棋盘最早640ms启动火浪，播放依据是 `fire-start`。首格约700ms、末格约1144ms，不等清除完成。忙碌/冻结会后移。 |
| 裂地冲击（预留） | `quake-start`启动裂纹推进；逐列间隔44ms，不能用最终effect代替起始。 |
| 陨石坠落（预留） | 下降与撞击分开；最早1600ms结算，仍须等待目标棋盘条件，以实际effect为命中依据。 |
| 炸弹投放（预留） | 最早1800ms真正引爆，忙碌/冻结可延后；投放、引信不等于爆破。 |
| 时间冻结 | cast时立即冻结3秒；真实试听0ms只响一次。视觉冰封约640ms，不因此推迟控制生效。 |
| 黑洞吸引 | 实际card-change启动420ms方块牵引；安定棋盘可0ms开始，忙碌/冻结时等待真实动作。视觉本体不早于640ms。 |
| 混乱风暴（预留） | 实际card-change改变6个普通块颜色时反馈，安定棋盘可立即提交；视觉落地时间另行处理。 |
| 迷雾领域（预留） | cast立即生效6秒；当前实现是落点附近4×4区域，按边缘与空洞裁剪。视觉消散不延长状态。 |
| 超载模式（预留） | cast激活10秒、得分×2；一次启动反馈，持续期间安静。 |
| 贤者时间（预留） | cast激活5秒，每650ms尝试自动操作；启动一次，其余操作沿用核心反馈。 |
| 彩虹核心（预留） | 实际card-change目标index转成万能块时反馈；目标tile id不符则失效，不伪造转换。 |

通用阶段参考当前视觉：释放0ms、飞行180–560ms、命中560ms。本页“顺序对照”把本体统一放在640ms，仅用于声音衔接比较。以上均未写入正式游戏事件映射，也没有改变任何规则结算。

## 音量、层级与风险

当前正式对战BGM倍率0.60，大厅0.66，普通消除0.46；特殊消除倍率按当前清单原值（0.28–0.56）。本轮候选倍率：释放0.30、飞行0.24、命中0.34、本体0.38。BGM在页面核心反馈期间模拟保留65%；没有修改正式音频配置。

同组A/B/C按最强50ms窗RMS匹配，并统一播放倍率，单文件峰值不超过0.58。短音不采用整段RMS拉响稀疏冰裂；不压缩、不变调、不变速。客观强度匹配并不等同于人耳等响，风格、舒适度、记忆点与最终优先级仍需用户试听判断。

- 单次施法：释放、飞行较轻，本体负责材质识别；火焰C细碎颗粒可能在BGM下较弱，需要注意可辨识度。
- 冻结、幸运星和黑洞可能与释放同刻响起；铃与琴的瞬态有互相遮盖风险。
- 跨组复用的铃、微光、风素材可能降低技能之间的区分度；尤其命中C与幸运星C来自同一微光源，命中/幸运也要与现有特殊消除区分。
- 双方连续施法：参考3条上限时实测跳过13次触发，最高3条同时发声；8条压力对照最高7条，全部30次触发播放。后续正式接入需单独设计优先级，不能靠增大音量或无限加实例解决。
- 保守离线混合：A/B/C三套 × 四技能及双边场景，共15种；使用真实正式BGM和消除文件，甚至不压低BGM、不限制重叠。最大采样峰值约0.572（约−4.85dBFS），未见削波。这仅覆盖给定组合，不代表所有设备、人耳舒适度或未来事件映射都已验证。
